# Source-rebuilt components above frozen F

All 32 non-Foundation binary inputs are generated by source recipes and compared
with accepted size/SHA-256 values before consumption. No non-F binary seed,
generated assembly staging snapshot or pinned symbol map remains in this capsule.

The five retained files are the intentionally frozen F.bin, the accepted manifest,
the native component catalog, and the two terminal Python source files. These are
the admitted platform input, provenance/catalog data and ordinary source pins.
F is never assembled. The full MIT license remains at the repository root.

Three recipes reconstruct the inputs in order:

- rebuild_component_inputs.py: five Foundation RAM helpers and CLOCK.
- rebuild_mon_services.py: MON and shared runtime sectors.
- rebuild_util_dev_inputs.py: FLASH, full MAINT, SRAM/WORK, ASM/DBG and erased fill.

Generated utility maps and AP loader sources now come from the same source build.
SOURCE-RECONSTRUCTION.json records all 32 exact comparisons; the two detailed
MON/SERVICES and UTIL/DEV receipts record their source hashes. Runtime banners,
short commands, addresses, CPU variants and hashes remain those of the qualified kit.

This source reconstruction does not authorize publication, repository/release
migration or changes to historical releases. Ownership/content review remains pending.


The sanitized export replaces only terminal/nf_console.py with an opt-in local
profile implementation. LOCK.json pins its new bytes and records the original
accepted host SHA-256. host_source_overrides is restricted to that terminal
source. The original accepted manifest is not rewritten; no firmware expectation
or frozen F hash changes. The terminal host change is not live-board qualified.
