# Alpha30 I2C hierarchy on board 2205

Alpha30 moves `I2C` to the top display level, with `MCP79XXX` and its RTC,
SRAM, and EEPROM lines nested below. EEPROM record format and commands remain
unchanged.

Board 2205 (W65C02SXB, EDU attached, COM3, FT245 serial `A10MPUPNA`) was
running a29 with valid EEPROM settings and autostart disabled. Two independent
complete E/F readbacks matched the canonical a29 image, SHA-256
`50e7414de00923b254ecb32f323076bc254be8b1c4ca63d5150c44bfe7661e4b`.

The a30 RTC, EEPROM, monitor, load, flash, interrupt, and guarded updater host
checks passed. The exact-image RAM updater installed E then F with on-board
verification. An independent E readback matched SHA-256
`b4f8d479cfbc73197728b2d31b776499d11a5e26d65b5c544d30057b56b1d278`.
The complete E/F readback was byte-identical to the canonical a30 image,
SHA-256 `1e844511971dc21ea867fef48d3e96540f51087e9fefb527a2302ea3b63eb667`.

Software reentry displayed:

```text
STR8-N 2.0a30 B3 65C02
ABI 65C02 | 816E | 816N-VEC
EDU KIT       DETECTED
I2C           READY  VIA1 @ $7FC0
  MCP79XXX
    RTC       $6F  Wed 26-09-30 22:16:17
    SRAM      $6F  64 BYTES
    EEPROM    $57  VALID
      AUTOSTART    DISABLED
      TARGET       B3 $F007
      DELAY        1.0 SEC
B3>
```

`C` returned `C 00 03 F007 0A`, confirming the saved settings survived the
update. A physical RESET was not captured for this installation. Transcripts,
receipts, and readbacks are under `BUILD/board/a30-2205/`.
