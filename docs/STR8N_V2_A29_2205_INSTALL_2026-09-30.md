# Alpha29 VIA1 base display on board 2205

Alpha29 adds `VIA1 @ $7FC0` to the I2C status line; the rest of the alpha28
display and EEPROM behavior are retained. `$7FC0` is the CPU register base of
the VIA used to bit-bang I2C, while `$6F` and `$57` are 7-bit I2C addresses.

Board 2205 (W65C02SXB, EDU attached, COM3, FT245 serial `A10MPUPNA`) was
running a28 with valid EEPROM settings and autostart disabled. Two independent
complete E/F readbacks matched the canonical a28 image, SHA-256
`2768bc484d6f68cd37dde6cfab1f8645862ceab6153cb4e3b5337fd48e7b1e3f`.

The a29 RTC, EEPROM, monitor, load, flash, interrupt, and guarded updater host
checks passed. The exact-image RAM updater installed E then F with on-board
verification. An independent E readback matched SHA-256
`4a93a1997c61e9b7b745e1efdaf801610a4fb2771d39cb858fd5ad1586b54a72`.
The complete E/F readback was byte-identical to the canonical a29 image,
SHA-256 `50e7414de00923b254ecb32f323076bc254be8b1c4ca63d5150c44bfe7661e4b`.

Software reentry displayed:

```text
STR8-N 2.0a29 B3 65C02
ABI 65C02 | 816E | 816N-VEC
EDU KIT       DETECTED
  I2C         READY  VIA1 @ $7FC0
  MCP79XXX
    RTC       $6F  Wed 26-09-30 22:03:05
    SRAM      $6F  64 BYTES
    EEPROM    $57  VALID
      AUTOSTART    DISABLED
      TARGET       B3 $F007
      DELAY        1.0 SEC
B3>
```

`C` returned `C 00 03 F007 0A`, confirming the saved settings survived the
update. A physical RESET was not captured for this installation. Transcripts,
receipts, and readbacks are under `BUILD/board/a29-2205/`.
