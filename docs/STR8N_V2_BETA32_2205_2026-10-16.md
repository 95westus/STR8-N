# Complete beta32 prerelease on 2205

Board 2205 (USB A10MPUPNA, COM3, 65C02) now runs the sealed 2.0b32
prerelease in B3, default MONITOR B generation 0000002C. Beta28 remains
valid and boot-tested in MONITOR A generation 00000028. Both 2205 and 2512
now have the complete beta32 prerelease environment; this is not promotion
to stable 2.0 and includes no v2.1 alpha code.

The complete B2 image and B3 executable regions match 2512. Native MAINT
2.4, SRAM 1.4, WORK 1.4 and EDU 1.4 launch directly or inside BATCH.
CLOCK 1.9 is available through 2205's existing B1 CLOCK flash record and
its SPI SRAM CLK record. CLOCK remains a RAM-loaded program. The older
MAINT saved record in B1 was preserved; the active native MAINT is 2.4.
Board-specific data and retained user banks are deliberately independent.

Before installation, all four flash banks, all 128 KiB SPI SRAM, EEPROM,
RTC SRAM and readable RTC settings/history were backed up and repeat-checked.
Application RAM $0200-$64FF was preserved and restored byte-for-byte.

The exact 15-sector plan updated B3:C; B2:F through B2:8; B1:D through
B1:B for CLOCK; B3:E; B3:A; and finally B3:B. The fixed recovery sector,
B0 WDCMON copy, B1 MAINT record, remaining B1 sectors, B3 per-board tail and
B3:D were preserved. The journal accounts for all 15 erase attempts.
Whole-bank preimage checks and transfer checks run before each erase;
record validity is committed after verification, with beta32 committed last.
Exact installer execution, stale/corrupt refusal and functional model tests
passed before any hardware flash writes.

Hardware verification passed for:

- Installer return, beta28 fallback selection and J3 return to beta32.
- Complete four-bank flash readback against the prepared target.
- All four native utilities and flash/SRAM CLOCK 1.9.
- `BATCH SRAM;G CLK;Q` and `BATCH SRAM;G CLK;STATUS;Q`.
- BATCH completion, stopping on errors and ESC cancellation without saving
  the temporary NAME test.
- Exact expected 128 KiB SRAM image, including the CLK update and unchanged
  workspace starting at byte 32768; no storage format was performed.
- Unchanged EEPROM, protected identity/status, RTC SRAM, history, trim,
  control and saved offset (-05:00). RTC time was allowed to advance.
- Restored original application RAM, with no pending restoration.
