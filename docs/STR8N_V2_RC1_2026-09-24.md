# STR8-N 2.0 RC1 decision

Date: 2026-09-24. RC1 packages the **unchanged** frozen `2.0a21` image. This
is an operator-approved release candidate for W65C02SXB board management with
a connected, enumerated USB FT245 host and stable 5 V board power. The RC
designation does not imply that every alpha19 board test was repeated on
alpha21.

## RC1 scope

RC1 covers the W65C02SXB/65C02 board-management firmware through FT245 under
the [host-connected operating conditions](STR8N_V2.md#supported-host-connected-operating-scope).
The same firmware is designed for W65C02SXB or W65C816SXB, with or without
the matching EDU daughterboard; the EDU is optional for core monitor operation.
W65C816SXB and EDU hardware remain outside the accepted RC1 claim until their
first-board results are recorded and signed on the
[qualification checklist](STR8N_V2_RC1_816_QUALIFICATION_CHECKLIST.md).
STR8-N manages board configuration, bank selection, boot access, and guarded
flash operations. Guests in the 8-xxx layer own application displays, LED
patterns, sounds, and other application behavior.

ACIA receive/fallback remains unresolved under [STR8N-001](issues/ACIA_RX_2512_2205.md).
W65C816, EDU-specific visual behavior, broader guest compatibility, and
interruption recovery are outside this RC claim. No interruption-recovery
claim is made because an active write or configuration change can leave an
incomplete or unbootable image, possibly requiring external reflashing; V2
has no persistent transaction record or automatic rollback, and those states
were not qualified. Ordinary power-off after completed work is within scope.

## Artifact identity and redistribution boundary

The RC ZIP is built by `python tools/package_v2_rc.py`. It copies only the
allowlisted STR8-N BIN/S19 images, project-authored RAM flash tools, host
bridge, [package README](STR8N_V2_RC1_PACKAGE_README.md), license, and
manifest. It checks frozen firmware SHA-256 values against the alpha21 freeze
manifest and checks the packaged E-F image's Bank 3 F slice against the
byte-exact physical board readback. The repository's frozen source snapshot
remains the source identity, but it is not in the public ZIP.

The WDCMONv2 RAM installer is independently authored STR8-N code. It accepts
the separate 4096-byte alpha21 top BIN, validates its expected hash, preserves
stock Bank 3 in an erased Bank 0, and requires physical RESET after verified
installation. The alpha21-specific stock migration was structurally and
host-checked, not run on factory hardware. No WDCMONv2 firmware or owner bank
archive is packaged. See the [provenance record](WDCMONV2_MIGRATION_PROVENANCE.md).
