# Alpha32 inventory and crypto status on board 2205

Alpha32 implements the selected fixed-column startup inventory. It keeps the
monitor's established banner, ABI line, and public entry points. The E-sector
extension checks the RTC as before, reads EEPROM settings, then wakes the
ATECC608-family device at seven-bit I2C `$60`. It issues Info Revision, one
four-byte configuration Read for lock bytes 86–87, and read-mode Counter 0/1.
Each reply has a bounded length and verified CRC. The chip is returned to Sleep.
A missing chip or invalid response prints `UNAVAILABLE` and does not block the
prompt. The 23LCV1024 line is labeled `LIST` because startup does not probe it.

## Board result

Board 2205 is the W65C02SXB with EDU on COM3, FT245 serial `A10MPUPNA`.
Two independent full E/F readbacks before installation matched alpha31 exactly:
SHA-256 `f78708db69ea32968e3136c4d056d8bf3bd7a2132134e890179501211062b330`.
The guarded RAM updater installed E first and F second. An independent E
readback after the first phase matched the alpha32 E candidate exactly:
SHA-256 `8c7de57b5610809bee6289bbe0e4e89cdb180560e55682f4f43b9788bc2c372b`.
The post-F full E/F readback matched the alpha32 candidate byte for byte:
SHA-256 `09658d2872476b6ea9255ea270c00e7682b7a3232dd7b415efa92ec147021046`.
The updater verified each phase and software reentry reached `B3>`. A physical
RESET and power cycle were not performed in this run. A subsequent user-requested
software reset through `G F004` completed with the alpha32 inventory, valid
EEPROM settings, crypto responding, and a `B3>` prompt. The complete capture
is saved as `reset-complete.jsonl` in the evidence directory.

The final reentry displayed this layout (RTC time is the observed run):

```text
STR8-N 2.0a32 B3 65C02
ABI 65C02 | 816E | 816N-VEC
SYSTEM CONFIGURATION
  EDU KIT         DETECTED
  I2C CONTROLLER  VIA1 @ $7FC0

DEVICE          BUS   ADDR  STATUS
MCP79XXX RTC    I2C   $6F  RUNNING 26-09-30 23:31:29
MCP79XXX SRAM   I2C   $6F  64 BYTES
MCP79XXX EEPROM I2C   $57  VALID
ATECC608        I2C   $60  RESPONDING
23LCV1024 SRAM  SPI    --  128 KB LIST

CRYPTO STATUS
  REVISION       00006003
  CONFIG LOCK    UNLOCKED
  DATA/OTP LOCK  UNLOCKED
  COUNTERS       00000000 / 00000000

BOOT SETTINGS
  AUTOSTART      DISABLED
  TARGET         B3 RESET VECTOR
```

`MCP79XXX SRAM` and `23LCV1024 SRAM` capacity lines are descriptive inventory;
startup does not test those memories or the battery. Crypto lock and counter
values come from the current chip replies and do not imply provisioning.
The earlier [full information read](STR8N_V2_CRYPTO_INFO_2205_2026-09-30.md)
records serial, all configuration bytes, and other informational responses.

## Validation and compatibility

The assembled startup check exercised responding and absent crypto devices,
CRC failure, absent RTC, console return, and VIA restoration. The monitor,
loader, flash, interrupt, RAM ABI, and S/R regressions passed. The guarded
updater model passed exact preimage, ordering, cancellation, refusal, and
flash-failure cases. The B3:F resident, RAM worker, and vector mappings match
alpha31; the E descriptor and S/R entry addresses remain fixed. E is fully
allocated through `$EFFF`, and F retains three bytes before the vectors.

Build and check with `make v2-a32-check`. The board-specific updater requires
the exact alpha31 preimage and independent E readback before the F phase.
