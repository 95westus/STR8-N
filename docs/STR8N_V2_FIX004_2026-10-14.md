# STR8N-004 APPS candidate — October 14, 2026

`BUILD/v2-fix004` fixes the corrupt APPS listing in a separate, unflashed
candidate based on `BUILD/v2-time-local`. The prior local-only TIME change,
detailed R CLOCK and startup FIFO/key behavior are retained.

The later RTC kernel builder created the native descriptor-table header but
left all eight rows erased. APPS printed each erased name as twelve `$FF`
bytes followed by `not installed`. The exact parent E image reproduces that
failure in the instruction model. Cached final readbacks from 2604 and 2609
also contain the erased rows.

Empty rows are now initialized to zero in both the candidate and the reusable
kernel builder. APPS checks the table magic/version/count and accepts only
1–11 uppercase ASCII letters followed by zero padding before printing a name.
It uses the existing read-only native-app probe to verify commit, descriptor
CRC, ABI, ranges, workspace, app header/image and exception vectors before
printing `installed`. A readable named row that fails the probe prints
`not installed`; erased/malformed rows produce no console bytes.

APPS lists native AP descriptors. MAINT, CLOCK, SRAM, WORK and EDU are separate
SR saved-program records accessed with T/R. An empty native table correctly
has no APPS rows. The B3 journal reservation continues to refuse native apps.

Only `str8n-v2-recovery-e000-efff.bin` differs from the TIME candidate:

```text
SHA256 d999ab7f2f9029eb36796e4095903de5b8e92d3ef760ee65e0db584aaeca5ec7
```

The E000-E7FF launcher uses 1760/1760 code bytes. All existing private entry
addresses remain fixed; E800-EFFD saved-program/status code is unchanged.
Both E seals verify to CRC zero. F/A/B, RTC/SPI, MAINT, CLOCK, storage and the
two TIME/status assets are byte-identical to the parent. A second build
produced identical binaries throughout the candidate directory.

Six instruction-model suites pass:

- `test_v2_fix004.py`: exact parent failure, zero/erased/malformed rows, table
  header faults, all eight/sparse slots, 1/11-character names, declared missing
  apps, valid B0/B1/B2 apps and exact metadata, B3 refusal, eight installation
  faults, arguments and actual native launch. APPS and T are checked under
  monitor A/EDU ON and monitor B/EDU OFF. Flash, EEPROM, RTC, SRAM, user RAM,
  bank selection and stack remain intact during listing.
- `test_v2_time_local.py`: exact local-only TIME, failure paths and detailed
  R CLOCK queries.
- `test_v2_startup_fifo.py`: drain bounds, stale/fresh keys and RAM edit.
- `test_v2_compact_boot.py`: local boot formatting, rollover and full queries.
- `test_v2_board_name_power_fail.py`: STR8N-006 label boundaries.
- `test_v2_storage.py`: saved-program/service paths, preservation, MAINT
  flash/SRAM transfers and interrupted/refused transfers.

Build with `python tools/build_v2_fix004.py`. Set
`STR8_RTC_BUILD=BUILD/v2-fix004` when running the model suites, then run
`python tools/build_v2_fix004.py --audit`. The candidate's
`qualification-summary.json` binds all six receipts, core/asset hashes and
build/test source hashes. No serial ports or boards were accessed or flashed.
