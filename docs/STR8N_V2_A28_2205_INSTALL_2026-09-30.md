# Alpha28 display update on board 2205

Board 2205 (W65C02SXB, COM3, FT245 serial `A10MPUPNA`, EDU attached) was
running a27. Two independent complete E/F readbacks matched the canonical
a27 image, SHA-256
`d64bb6738d13690d9a12f66ea248c89cb838de947c06203301d5e41fc8f40fc1`.

Alpha28 changes the I2C display to the selected option 2 layout and retains
the alpha27 EEPROM format and commands. RTC, EEPROM, monitor, load, flash,
interrupt, and guarded updater host checks passed. The exact-image RAM updater
installed E and then F, each with on-board verification. An independent E
readback matched SHA-256
`ec0a137ee004a2d38405be47e064ebfc5463d95258b6e0a5b32bf018c9478a02`.
The full E/F readback was byte-identical to the canonical alpha28 image,
SHA-256 `2768bc484d6f68cd37dde6cfab1f8645862ceab6153cb4e3b5337fd48e7b1e3f`.

Software reentry displayed:

```text
STR8-N 2.0a28 B3 65C02
ABI 65C02 | 816E | 816N-VEC
EDU KIT       DETECTED
  I2C         READY
  MCP79XXX
    RTC       $6F  Wed 26-09-30 21:26:23
    SRAM      $6F  64 BYTES
    EEPROM    $57  VALID
      AUTOSTART    DISABLED
      TARGET       B3 $F007
      DELAY        1.0 SEC
B3>
```

The `C` command returned `C 00 03 F007 0A`, confirming the EEPROM setting
survived the flash update. Autostart remains disabled. This installation did
not include a physical RESET capture. Serial transcripts and readbacks are
under `BUILD/board/a28-2205/`.
