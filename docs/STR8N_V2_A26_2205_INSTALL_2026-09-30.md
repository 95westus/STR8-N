# Alpha26 board 2205 installation and EEPROM qualification

Board 2205 is a W65C02SXB with the EDU/MCP79411 attached, on COM3 with
FT245 serial `A10MPUPNA`. Its live monitor was a25, so the guarded normal
E-then-F update used the exact a25 image as its starting point. Two independent
pre-update 8 KiB E/F readbacks matched SHA-256
`8697674a8c2944e4a6d3a6dbe5cdf31d1ab11e037556278e716953f81c7b7d41`.

The updater verified each programmed sector on the board. A full readback
after E installation matched the new E sector. After F installation, a full
E/F readback matched the canonical a26 image byte for byte (SHA-256
`62656ba960292c11104d15457b1a0ddb5480011eacdffd7fa1b3079d981127ae`).
A second full readback after EEPROM configuration tests had the same hash.

The startup display identified a26, EDU `DETECTED`, and an advancing RTC.
EEPROM initially reported `EMPTY` and `SETTINGS NONE`. On hardware:

- The first confirmed save created A (generation 0); the second changed save
  created B (generation 1). Readback showed both records.
- Saving unchanged settings caused no record change. Canceling a change and
  entering an invalid bank or delay also left the records unchanged.
- Enabled autostart to the safe warm-monitor entry B3 `$F007` was tested with
  the `S` hold key and with the full 2.0-second countdown and handoff.
- A RAM probe deliberately invalidated the older copy's commit marker using
  the EEPROM writer. The next monitor entry reported `RECOVERED` and used the
  newer copy. Saving again repaired the pair; startup reported `VALID`.
- Final settings were saved as **autostart disabled**, B3 `$F007`, 1.0 second.
  The records were A generation 2 and B generation 3. After the user pressed
  physical RESET, the board displayed these settings and `EEPROM VALID`.

The captured physical RESET display was:

```text
STR8-N 2.0a26 B3 65C02
ABI 65C02 | 816E | 816N-VEC
EDU KIT       DETECTED
  RTC         Wed 26-09-30 20:14:41
  EEPROM      VALID
    AUTOSTART DISABLED
    TARGET    B3 $F007
    DELAY     1.0 SEC
B3>
```

The later `C` command displayed `C 00 03 F007 0A`. The host test suite
`make v2-a26-check` and the guarded 2205 updater tests passed. Board transcripts,
readbacks, and installer receipts are in `BUILD/board/a26-2205/`.

This test verifies EEPROM storage across physical RESET and recovery from one
invalid record. A battery removal or full power-off persistence test was not
performed. The RTC battery-backed SRAM is not used for these settings.
