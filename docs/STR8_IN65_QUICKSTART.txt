STR8-iN/65 QUICK START
Factory WDCMONv2 -> STR8-N 1.35

The v1.35 factory path is not board-qualified. The following board evidence
applies only to the preceding v1.34 build, not the current payload.

The complete v1.34 factory migration passed on SXB2 HW 3.00 / WDCMON 2.00
with BF/B5 flash on COM4, 2026-09-15.  That run did not add visual LED
observations; the migration's operator-observed $F0 cue was accepted in the
v1.32 run on 2026-09-08.

WINDOWS 11 HOST - v1.34 BOARD-PROVEN WITH PHYSICAL RESET ARM

The accepted v1.34 run used -PhysicalResetArmSeconds 60 on the Windows
launcher, then physical RESET while its arm window was active.  See
DOC\WDCMONV2_MIGRATION.md for this option if the default reset/Enter gate
misses the WDC monitor.

NEEDED
- Windows 11 with Windows PowerShell 5.1 (powershell.exe).
- The board's USB COM-port driver; the powered board must appear as COMx.
- This ZIP extracted to a writable location.  It creates the surrounding folder
  STR8-N-v1.35-Migration-Kit; work inside that folder.
- A free COM port, stable power, and access to the board's physical RESET button.

NOT NEEDED
- Git, Python, make, WDC tools/WDCDB, internet access, or a T48 programmer.
- Administrator rights, except possibly to install the USB COM-port driver.

Optional preflight (the second command should list the board's COM port):

   $PSVersionTable.PSVersion
   [System.IO.Ports.SerialPort]::GetPortNames()

Extract the migration ZIP, connect and power the WDC board, then run:

   powershell.exe -NoProfile -ExecutionPolicy Bypass `
     -File .\STR8-iN65-LOADER.ps1

BOARD UPDATE STEPS (SAME FOR WINDOWS OR AN EXPERIMENTAL LINUX HOST)

READ THE SCREEN AS YOU GO.  The loader tells you when to type a command and
when to press a control key.  Ctrl+U and Ctrl+D send different packaged files;
press each key only when the screen asks for it, and press it only once.

1. Select or supply the serial port and press physical RESET when asked.

2. When the board has qualified erased Bank 0, type:

   COPY B3 TO B0

3. Wait for the complete 32K copy and exact comparison to pass.  When the
   board prints SEND STR8-N TOP BIN, press Ctrl+U once.  After the 4096-byte
   image passes its board-side check, type:

   INSTALL STR8-N 1.35

   On a connected EDU, require solid LED $F0 (all red on, all green off)
   during each active copy/install flash interval.  It clears only after the
   corresponding verification succeeds.  The terminal warning remains the
   authority when the optional LEDs are absent or not visible.

4. After STR8-N 1.35 starts, select S.  At STR8-N> enter L, then press Ctrl+D
   once to send the packaged production Bank Maintenance S19.

5. At BM> enter D.  Enter Bank 0, type FF, and description WDCV2.  Require
   this exact proposed write:

   PROPOSED D0 B3:$FFB0: FF FF FF FF 57 44 43 56 32 FE FF FF FC FF FF FF

   Then type:

   ADOPT B0

6. Use M and require:

   D0 FF WDCV2 FFFF FCFFFFFF

   Test reset selector 0 and shell J0.  J0 hands the computer completely to
   the preserved factory system in Bank 0.  To leave that system and return to
   STR8-N 1.35, press the board's physical RESET button.  Requiring physical
   RESET after J0 is intentional and by design; it is not a flaw or a failed
   migration.

SAFETY

Do not press RESET, assert NMI, disconnect USB, or remove power while ERASE
or PROGRAM is displayed.  Bank 0 remains an opaque byte-for-byte factory
guest.  Its D0 record is stored only in the Bank-3 directory.

EDU LED QUICK REFERENCE - IMPLEMENTED v1.34 PATTERNS

Red LEDs are bits 7-4; green LEDs are bits 3-0.  Below, bits run from 7 to 0;
1 means illuminated.  These meanings apply while STR8-N owns the display.

Value  Red / Green  Meaning
$00    0000 / 0000  Display released to the next application.
$01    0000 / 0001  Running; also the resident flash worker's return state.
$21    0010 / 0001  Waiting for input; FTDI unconfigured or suspended.
$43    0100 / 0011  Waiting for input; FTDI configured.
$07    0000 / 0111  Receive activity.
$0B    0000 / 1011  Transmit activity.
$F0    1111 / 0000  Flash mutation or its required verification is active.

All red on, all green off ($F0): leave RESET, NMI, USB, and power untouched
during the active flash operation.  Follow the terminal's prompts and result.
The migration/restore RAM tool clears $F0 to $00 after successful verification
before waiting or handing off.  The resident worker returns to $01 on both
success and failure.  Neither $01 nor all LEDs off alone means success.

Activity latches until another state replaces it; there is no periodic
heartbeat.  $43 does not prove a terminal is open.  Host presence is sampled
at the main command wait, so a host change may appear only on the next wait.
Once HIMON, ASM-F2, or a WDC/user application takes over, it owns the LEDs
and may assign different meanings.  Proposed detailed error patterns are
not implemented v1.34 diagnostics; $41 is an earlier input-wait pattern.

This card includes the legend for offline use.  The full Operator's Guide
in the source repository is docs/OPERATORS_GUIDE.md, "EDU LED patterns (v1.34)":
https://github.com/95westus/STR8-N/blob/main/docs/OPERATORS_GUIDE.md#edu-led-patterns-v134

DETAILS

Add -Details to the Windows command or --details to the experimental Python
command to show the image SHA-256, T48 offset, bank policy, and evidence paths
before starting.  Fast and detailed modes both retain the complete raw
transcript and timestamped host event log in LOCAL.
Execution Policy Bypass applies only to the launched PowerShell process and
does not change the machine's permanent PowerShell policy.
The complete procedure and recovery notes are in DOC\WDCMONV2_MIGRATION.md.
