# Alpha31 memory retention and SPI display on board 2205

Alpha31 adds the agreed descriptive SPI inventory and retention labels for
MCP SRAM, MCP EEPROM, and SPI SRAM. It does not access SPI, probe its capacity,
check a backup battery, or change EEPROM settings. Battery-backed describes
retention with a working backup supply; both SRAM devices remain volatile.
The static SPI inventory also appears if EDU detection is inconclusive.

## Layout and compatibility

B3:E uses 3,652 of 4,096 bytes, leaving 444 bytes free: 255 before `$E800`,
72 before `$ED00`, and 117 before `$F000`. B3:F retains 3 bytes before vectors.
S/R, flash worker, and vector symbols match alpha30. Public entry points and
EEPROM record format remain unchanged. The F image updates the version banner.

Run `make v2-a31-check` for RTC, EEPROM, monitor, loader, flash, interrupt,
and S/R regression checks. The board-specific updater test additionally checks
exact preimages, installation order, cancellation, refusal, and flash failure.

## Board evidence

Board 2205 is W65C02SXB with EDU, COM3, FT245 serial `A10MPUPNA`.
Two independent complete E/F preimages matched canonical alpha30, SHA-256
`1e844511971dc21ea867fef48d3e96540f51087e9fefb527a2302ea3b63eb667`.
Before installation, EEPROM settings were valid: autostart disabled, B3 reset
vector target, and 6.4-second delay.

RTC, EEPROM, monitor, loader, flash, interrupt, S/R, and guarded updater
host checks passed. The guarded RAM updaters installed E then F with board
verification. An independent E readback matched the candidate; the complete
E/F readback was byte-identical to alpha31, SHA-256
`f78708db69ea32968e3136c4d056d8bf3bd7a2132134e890179501211062b330`.

`C` returned `C 00 03 V 40`, confirming unchanged settings. Software reentry
printed the following. Physical RESET and power-cycle tests were not performed.
Transcripts, readbacks, and `verification.json` are under
`BUILD/board/a31-2205/`.
