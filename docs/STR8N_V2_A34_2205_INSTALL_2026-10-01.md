# Alpha34 VIA display on board 2205

Alpha34 changes the startup controller line to:

```text
  VIA1 $7FC0  A:I2C  B:SPI
```

The version banner advances to `STR8-N 2.0a34`. The device inventory remains unchanged; the SPI SRAM entry still says `LIST` because startup does not probe that device.

Board 2205 is the W65C02SXB with EDU on COM3, FT245 serial `A10MPUPNA`. The prior alpha33 E/F image was matched against its archived, verified board readback. Exact-preimage RAM updaters installed the alpha34 E and F sectors separately. The E sector was read back before the F update; a final `D E000 FFFF` readback matched the complete alpha34 build byte for byte. Software reset with `G F004` displayed the alpha34 banner, the VIA line, valid RTC and EEPROM status, the crypto serial number, and the `B3>` prompt.

The alpha34 display and full host regression tests passed. The guarded E/F updater model tests passed, including preimage mismatch refusal and sector isolation.
