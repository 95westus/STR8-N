## Current operator and memory notes

Launch `MAINT`, `SRAM`, `WORK` and `EDU` directly at the monitor prompt.
Compatible R-prefixed forms still work; `R` otherwise restores/runs saved
RAM programs. These native utilities run from reserved B2 flash. B1 is
entirely erased/free on 2512; B0 remains an opaque retained image. Erased
bytes inside reserved B2/B3 allocations are not user storage.

The native bundle uses 22,012 of 22,528 bytes, leaving 516 bytes. The separate
battery/wear helper uses 2,302 of 2,560 bytes, leaving 258 bytes. Beta32 adds
no RAM reservation; existing protected BATCH RAM is 156 bytes. CLOCK 1.9
remains an 11,224-byte RAM program at $2000–$4BD7, saved under CLOCK and CLK
in SPI SRAM. `BATCH SRAM;G CLK;STATUS;Q` loads it, queries status and returns
to the monitor. The queue stops on errors and Esc cancels remaining commands;
it never supplies confirmation answers automatically.
