# STR8-N 2.0a24c1 configuration guide

Version: **2.0a24c1**. Based on alpha24 at `56dd3f7`. The COM3 W65C02
installation, exact readback and software handoffs passed; see the
[board report](STR8N_V2_CONFIG_COM3_INSTALL_2026-10-01.md). Physical reset,
cold power and W65C816 qualification remain pending.

Historical `src/v2a24` sources remain unchanged. The retired a24 release
and tag have been removed; source history is retained.

For operation and addresses, use the [a24c1 manual](STR8N_V2_A24C1_MANUAL.md)
and [maps](STR8N_V2_A24C1_MAPS.md). a24c2 remains a separate RAM-layout proposal.

## Layout and behavior

The single 16-byte configuration record resides at **`$FFD0-$FFDF`**. Its format, two accumulated checksums,
`C` syntax, reset-only autostart and hold behavior remain unchanged.
The core owns configuration; no EDU, RTC or EEPROM is needed.

| Range in resident bank | Use |
| --- | --- |
| `$F000-$FFBC` | Core, including embedded RAM worker and vector code |
| `$FFBD-$FFCF` | 19 bytes of unused space |
| `$FFD0-$FFDF` | Configuration, erased in the factory image |
| `$FFE0-$FFFF` | Existing hardware vectors and reserved words |

The builder refuses code overlapping `$FFD0`. Configuration is associated
with the resident bank, independently of the selected target bank. Erased
or invalid configuration holds at the monitor. `M` remains a RAM editor.
`F` remains an explicitly guarded raw flash editor; it does not regenerate
configuration checksums. `I` retains its protected flash ranges.

`C` snapshots F into `$6900-$78FF`, changes only `$78D0-$78DF`, and uses the
RAM worker to program or erase/rewrite and compare the complete sector.
An unchanged save issues no programming or erase operations. Successful
verification returns to the prompt and restores the selected bank.

A failed core-sector write stays in RAM and displays `Flash fail; Y retry/reset`.
On failure, Y retries the complete staged sector with an erase; on successful
raw self-edit, Y restarts the monitor. A successful configuration retry returns
to the command that saved it. The emulation NMI dispatch gate stays closed
while the failed self-write waits in RAM. This is not protection against
physical NMI fetching damaged flash vectors, hardware failure or power loss.
Do not reset, press NMI or remove power during writing. External-programmer
recovery may be necessary after an interruption. There is one persistent copy.

## Public interface

ROM and RAM ABI addresses and capability flags remain fixed. ROM slots
`$F02E` and `$F031` remain reserved. The public include publishes configuration
address, size and format for read-only inspection with the resident bank
visible. Use C to save settings.

## Build and host checks

```text
make v2-config
make v2-config-check
```

The check target first verifies the frozen alpha24 baseline, then builds and
tests this candidate, including core regression, configuration failure/retry,
migration guards and configuration behavior.
Outputs are under `BUILD/v2-a24c1`. No `.a` carriers are generated by the
candidate build. Existing alpha24 packaging and stock-board migrators remain
specific to alpha24; do not substitute candidate binaries into those packages.
A separate [unified WDCMON to a24c1 installer](STR8N_V2_CONFIG_WDCMON_INSTALL.md)
is built with `make v2-config-wdcmon` and checked with
`make v2-config-wdcmon-check`.

## Installed-board updates

Use a board-specific guarded updater generated from the exact current board
readback. This stock-board release kit does not supply a universal updater
for an already installed STR8-N board. Preserve saved settings and verify
complete readback after any firmware update.

## Release identity

A configured F image differs from the factory BIN. Compare all firmware
bytes outside `$FFD0-$FFDF` with the release, validate the configuration
separately, and retain the hash of the complete observed image. Installers
still compare every byte against their exact staged sector, including the
configuration and hardware vectors. Host receipts do not imply board proof.
