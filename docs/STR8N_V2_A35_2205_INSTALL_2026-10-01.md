# Alpha35 section headings on board 2205

Installed alpha35 on W65C02SXB board 2205 with EDU, COM3, FT245 serial
`A10MPUPNA`. Startup now uses `[SYSTEM CONFIGURATION]`, `[CRYPTO STATUS]`,
and `[BOOT SETTINGS]` headings.

Guarded E/F RAM updaters checked each exact alpha34 live sector before writing.
The builder inputs were copies of the archived verified alpha34 readback.
The complete E readback matched before F installation; the final 8192-byte E/F
readback matched the alpha35 build byte for byte. SHA-256:
`80133be1c52869df433be672547b8ebb02e2aa0792989a6adcef72ed53a8bd4e`.

Software reset through `G F004` showed the alpha35 banner, all three headings,
running RTC, valid EEPROM, responding crypto with the expected serial number,
preserved boot settings, and the `B3>` prompt. Physical reset and power cycling
were not tested. SPI SRAM remains listed, without an active device probe.

Build, display, shared host regression, and guarded updater model checks passed.
