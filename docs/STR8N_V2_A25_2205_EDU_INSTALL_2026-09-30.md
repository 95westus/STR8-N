# Board 2205 alpha25 guarded E/F installation

Date: 2026-09-30. Board: W65C02SXB with EDU attached. FT245: COM3,
serial `A10MPUPNA`, 115200 baud. This is a physical board result for the
alpha25 date/time display candidate.

## Preflight and images

Two separate `D E000 FFFF` captures produced identical 8192-byte B3:E/F
images, SHA-256
`2519c05ff558969b19401a702382a2986219b5e2d5f805d402deaa0552998d15`.
B3:E was all zero. B3:F matched the source-built alpha24 F BIN byte for byte,
SHA-256 `43e6ee966963e1cc401986581742cc75b302cd0a02cfaf22965fe7ab8a43ec1a`.

The [guarded builder](../tools/build_v2_a25_guarded_ef.py) pinned that
complete E/F preimage and embedded the exact old/new sector images in two
RAM installers. The F installer also requires the staged new E image.
The [flash-model check](../tools/test_v2_a25_guarded_ef.py) passed sequential
E/F writes, complete verification, wrong-image refusal, cancellation, and
RAM-only failure handling after an F write.

## Board sequence

1. The E RAM updater reported `B3:E exact; TYPE Y to repair>` before the
   confirmation byte. It reported `B3:E VERIFIED; RESET` after programming.
2. A full E/F readback matched new E and original alpha24 F byte for byte.
3. The F RAM updater reported `B3:F exact; TYPE Y to update>` after its new-E
   and old-F gates. It reported `B3:F VERIFIED; RESET` after programming.
4. The automatic monitor restart printed `STR8-N 2.0a25 B3 65C02`, the ABI
   line, then `DATE 26-09-30  TIME 18:10:04` before `B3>`.
5. An independent full B3:E/F readback matched the two new BINs byte for
   byte, SHA-256
   `c00f0ad1a7a1521008c508e4a3bfb84f6d62737dd2bcef565174434aa719ce4b`.
6. The owner pressed physical RESET during receive-only capture. The board
   printed the alpha25 banner, `DATE 26-09-30  TIME 18:11:06`, and `B3>`.
   Read-only `T 3` returned to the prompt without `SR unavailable`.

The owner-local captures, readback BINs, installer S19 files, and manifest
are in `BUILD/board/a25-guarded/`. No cold-power cycle, W65C816 EDU run,
or physical S/R save/restore was performed in this session. The earlier RAM
RTC program and this installed image both read an advancing MCP79411 time.
