# Alpha33 crypto serial number on board 2205

Alpha33 adds the selected serial-number line directly beneath the ATECC608
entry. Startup reads configuration words at byte offsets 0, 8, and 12 and
prints bytes 0–3 and 8–12 as the nine-byte serial number. The value is read
from the device on each startup; it is not embedded in the firmware.

```text
DEVICE          BUS   ADDR  STATUS
MCP79XXX RTC    I2C   $6F  RUNNING 26-09-30 23:49:52
MCP79XXX SRAM   I2C   $6F  64 BYTES
MCP79XXX EEPROM I2C   $57  VALID
ATECC608        I2C   $60  RESPONDING
  SERIAL                  01231454D6545F9FEE
23LCV1024 SRAM  SPI    --  128 KB LIST
```

The chip receives seven informational commands: revision, lock-state word,
two counter reads, and three serial-number words. Every reply has its length
bounded and CRC checked. Failed reads suppress the serial line and show the
crypto device as unavailable. Startup issues no provisioning or locking
commands and returns the chip to Sleep.

## Implementation and checks

Space was recovered by shortening the CRC bit loop, using monitor scratch
bytes `$E3-$E7` during the crypto transaction, sharing counter formatting,
and sharing the `LOCKED` text within `UNLOCKED`. Crypto results reuse
`$7DC0-$7DDB` after EEPROM reading completes. That range is separate from the
RTC sample, EEPROM settings/state, and live vector tables. E retains three
unused bytes. The build now counts the extra text block when reporting free
E-sector space.

The monitor, S/R, worker, vector, and extension entry addresses match alpha32.
The assembled display tests cover serial ordering, three alternative serial
values, invalid CRCs including the final serial word, malformed response
counts, device error replies, absent/stuck buses, nonzero counters, locked
zones, RTC hour conversion, VIA restoration, and return to the caller.
Monitor, loader, flash, interrupt, RAM ABI, and S/R regressions passed. The
guarded updater tests passed their preimage, ordering, cancellation, refusal,
and flash-failure cases. Run `make v2-a33-check` for build and host tests.

## Board verification

Board 2205: W65C02SXB with EDU, COM3, FT245 serial `A10MPUPNA`.

- Two independent E/F readbacks matched installed alpha32 exactly.
- E was installed and independently read back before F installation.
- Both updater phases verified their programmed sectors.
- The complete post-install E/F readback matched the alpha33 build byte for byte.
- Software reset through `G F004` displayed `STR8-N 2.0a33`, the serial line,
  valid EEPROM settings, and the `B3>` prompt.
- The displayed configuration/data lock states remained unlocked, and both
  counters remained zero. No EEPROM setting change was requested or made.

This run exercised software reset on the 65C02 board. Physical RESET,
power cycling, and the 816 board were not tested in this run.
