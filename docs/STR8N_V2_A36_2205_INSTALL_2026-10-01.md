# Alpha36 VT102 startup clear on board 2205

Installed alpha36 on W65C02SXB board 2205 with EDU, COM3, FT245 serial
`A10MPUPNA`. After the 160 startup dots, the monitor sends `ESC[H` (home)
and `ESC[J` (erase to end of screen), immediately followed by the banner.

Guarded E/F RAM updaters checked each exact alpha35 live sector before writing.
Builder inputs were copies of the archived verified alpha35 readback.
Complete E readback matched before F installation; final 8192-byte E/F
readback matched the alpha36 build byte for byte. SHA-256:
`b7486973ddb038775dc67c1b615a134c695c1c7ee1b72e720a84251dbf4528da`.

Software reset through `G F004` confirmed all 160 dots, the exact VT102 bytes,
the alpha36 banner and section headings, running RTC, valid EEPROM,
responding crypto, preserved boot settings, and the `B3>` prompt.
Terminal rendering was not visually inspected. Physical reset and power
cycling were not tested. Build, host regression, and guarded updater model
checks passed.
