# 3270 font for the printable checklist

Source font: IBM 3270 version 3.0.1 by the
[3270font project](https://github.com/rbanffy/3270font), distributed by
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/3270).
The original download is `3270NerdFontMono-Regular.ttf`, saved here as
`3270-Regular.ttf`. Its license is retained in `LICENSE.txt`.

`prepare_3270_pdf_fonts.py` keeps ASCII characters and creates regular,
synthetic bold, synthetic italic, and synthetic bold italic variants under
the distinct family name STR8N 3270. The PDF embeds these faces so no font
installation is needed by the reader. The font license is attached to the PDF.
