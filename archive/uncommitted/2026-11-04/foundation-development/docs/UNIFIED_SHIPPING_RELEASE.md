# Unified STR8-N shipping contract

One common MON/tool feature profile above frozen Foundation0.3.0/g1 BASE1/PR05,
with CPU-specific AP/02 admission envelopes for65C02 and816 emulation. MON A/B
use the same commands/source and differ in slot identity. Board names, boot
policy, RTC/calibration/history and SRAM layouts remain personal settings.

Candidate4 includes MON A/B g10, WB2/PROGRAM, CLOCK, SRAM/WORK, ASM/DBG g2 and
REC-loaded full MAINT/FLASH. Its compact92KiB allocation replaces the earlier
88KiB resident-tools /104KiB developer-preview budgets. The cleaned reference
boards have36KiB in erased sectors. Erased space on another board still needs
occupied-image review. Keep F golden for ordinary MON/tool installation.

The selected presentation remains Traditional g10. Foundation identity/purpose
lead, then MON and familiar board/RAM/EDU/SRAM/RTCC/wear/battery status.
VERSION adds CPU/ABI/slot details. Saved/read data supply the display; * marks
unmeasured health/prior wear. F's startup/countdown and bytes remain unchanged.

Use the [operator manual](NATIVE_UTILITIES_MANUAL.md),
[developer guide](DEVELOPER_MANUAL.md) and
[candidate4 status](UNIFIED_CANDIDATE_STATUS.md). They supersede earlier
current-status claims in historical checkpoint receipts. Qualification is one
profile with targeted CPU/I/O tests, not an assumption that every positive
write fixture ran on every board. Older raw private-ABI binaries are not
accepted solely because bytes are found at an old address.

The intended familiar b35 workflow now includes ASM/DBG. The current g1 REC
MAINT lacks later EDU SAVE/named-X front doors, so blanket full-b35 equivalence
must not be advertised. Saved EDU choices and normal copy/store/restore remain.
Candidate4 extracted-kit RAM acceptance passed on2512, including guided
terminal actions; the companion acceptance receipt records exact coverage.
The documented out-of-scope gates remain separate from accepted components.
No release publication or
new board operation is authorized by this document.
