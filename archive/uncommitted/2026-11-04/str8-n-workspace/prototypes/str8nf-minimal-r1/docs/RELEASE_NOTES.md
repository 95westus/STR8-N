# STR8N-F v0.2.0 — Boot & Recovery Toolkit

Released October 28, 2026. The primary download is the focused operator kit;
the separate source ZIP contains the unified source and optional components.
The earlier v0.1.0-preview.1 remains unchanged.

Included: exact 4096-byte b15/PR04 F, matching CONFIG/OPAQUE/DEMO/READBACK RAM
tools, optional BASE MON A/B, OIP1 packet preparation, quick start, image and
readback contracts, component destinations, manifests and kit integrity checker.

N/F requires no EDU/SPI/RTC or full-system utility banks. B0/B1/B2 remain
user-owned. Their existing contents are not cleared or reassigned. Detailed
system status and optional ES1/VX1/MAINT/FLASH development remain separate.

F SHA-256:
`1a1db354d49d8a9a555be1100b74f3e4b0ed14d3156f3a333086853a845717b8`.
It still identifies as 2.0proto b15 / 8000000F. All assembled payloads retain
their previous identities. Release preparation uses no assembly rebuild,
second build, CPU simulation or device installation. Existing evidence is
identified as inherited; the public summary excludes owner captures.

This is an early toolkit release, not stable 1.0 factory acceptance. A general
preserving WDC migrator, history import/repair, automatic live opaque installer,
physical ACIA acceptance and native 816 applications are not supplied. Raw L
uses an idle gap and has no declared length/transfer CRC. See
[release scope](RELEASE_STATUS.md).

SPI WORK message journaling, WTOR, login/session features, redesigned maps,
BASIC/Forth and relocated full-system personalities remain planned. No WDC
firmware, owner records, saved programs, SRAM or RTC/PF data are distributed.
